# 开发结构与状态

源码版本为0.1.0，当前实现包含分钟电量及离线日／月汇总。此源码整理版本已完成x64 Release编译与静态审阅，未启动应用、浏览器、测试或设备访问。源代码、构建成功、静态审阅、历史设备观察和运行结果分别看待，不以某一项代替另一项。

## 模块

| 模块 | 责任 |
|---|---|
| src/agent/main.cpp | Win32参数表、托盘、设置与退出 |
| src/agent/controller.cpp | 会话、取消、重连与快照发布 |
| src/agent/serial.cpp | Windows异步串口读写与资源释放 |
| src/agent/protocol.cpp | 有界收包、校验、协议字段解析及有限发送编码 |
| src/agent/storage.cpp | 分钟记录、CSV／日志、元数据、持久化与保留 |
| src/agent/energy.cpp | 电量账本、已提交／待写视图、历史恢复与汇总 |
| src/common | 配置、时钟、Windows对象与共享内存 |
| viewer/src | 本地文件导入、图表、筛选、导出与页签 |

数据流为串口→解析→状态中心／分钟统计→共享快照与CSV。界面、其他本机客户端和离线查看器的职责独立；显示速度不改变串口采集速度。

## 关键约定

保持接收、界面、CSV形成与批次写盘四种频率独立。串口关闭必须取消接收和重连并释放句柄；初始化不恢复设备设置。回传间隔只在用户明确应用时发送。

11项协议指标由 src/common/model.hpp 定义。今日用电是独立派生行，不扩充协议指标数组。电量仅在已有分钟或部分区间结算后增加；心跳读缓存，不重复重算全部待写记录。

共享内存JSON主版本1、次版本1，固定头部和对象名不变。客户端检查心跳与接收年龄，而不是仅检查映射是否存在。没有网络监听或设备控制API。

## 工作方式

默认进行代码实现、静态阅读、必要编译和脚本语法编译，不自动启动目标程序或执行测试。测试、浏览器运行验证、硬件联调和任何设备发送需要用户另行明确授权。

当前电量功能、恢复边界和离线HTML尚不能依据静态工作宣称已完成运行、故障恢复或性能验证。协议文档中的历史单机观察只适用于相应设备与回包，其他固件、传感器精度、热插拔、休眠、存储故障和长期运行仍需独立确认。

文档应引用仓库内可见文件，不依赖其他开发目录。更改接口同时更新 [IPC.md](IPC.md)、[ENERGY.md](ENERGY.md) 和查看器；更改查看器后重新文本组装已交付HTML。构建和工具准备见 [BUILD.md](BUILD.md)。
