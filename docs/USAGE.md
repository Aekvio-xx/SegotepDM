# DM Agent 使用

运行 DmTelemetryAgent.exe。首次没有保存端口时，选择电源对应的 USB 串口；启动自动连接默认开启，选定后连接并保存。HIMOS、串口助手与 Agent 应分别使用同一端口，不能同时占用。程序使用当前系统可用的串口驱动。

正常后续启动进入托盘。主窗口的关闭按钮仅隐藏；退出、查看状态、串口开关和设置可从托盘菜单进入。

## 界面与设置

参数表包含输入功率、今日估算用电、风扇转速、低压侧温度、输入电压、四路电压、输入频率、高压区温度和环境温度。温度三个区域始终同时采集。默认客户区 620×420 逻辑像素，随 DPI 调整，最小 580×390；这些是布局设定。

“连接串口”尝试打开已选设备，失败后有界退避重试；“关闭串口”取消本次任务、释放句柄并停止重连。下次启动按“启动时自动连接串口”设置处理，不由本次关闭动作决定。没有保存端口或配置损坏时不自动探测其他串口。

“启动时自动连接串口”和“用户登录后自动启动”是独立选项，后者默认关闭。自启动使用当前用户 Run 项，不需要系统服务；程序移动后需重新保存设置。锁屏可继续，注销结束，登录前不采集。

设置页提供 CSV 批次写入间隔、数据过期时间、保留天数及串口参数。当前默认 115200、8N1、无流控、DTR／RTS 关闭。串口打开期间不能编辑串口参数。

手动应用回传间隔支持 1000、1500、2000、2500、3000 ms。请求绑定当前设备会话，断连期间不排队；启动和重连不重放。写入完成只表示已发送，不表示设备已回读确认。

## 今日估算用电

电量以已有分钟平均输入功率乘有效时长累计，显示 kWh（度），保留三位小数。一般每分钟更新，断连、退出、跨日等部分区间也会结算；未收到有效覆盖时显示 --，关闭串口后保留累计并标暂停。每天本地零点结算旧日并开始新日。

电量只表示被监测覆盖的估算用电。未运行、休眠、断连和过期后的时间不补算；“已结算”不表示全天测量完整。重启恢复及字段见 [ENERGY.md](ENERGY.md)。

## 数据目录

均相对于程序所在目录：

~~~text
config/settings.json
config/devices.json
config/energy_history.json
data/telemetry_YYYY-MM-DD_v2.csv
logs/agent_YYYY-MM-DD.log
logs/agent_YYYY-MM-DD_001.log
viewer/DM-Record-Viewer.html
~~~

旧版 telemetry_YYYY-MM-DD.csv 保留供兼容恢复。新 CSV 包含 92 列，区分采样与日／月汇总。设备信息缓存按元数据版本关联记录，不能把额定电流当实时电流。

设备接收、分钟汇总、界面刷新和写盘彼此独立。串口持续异步接收；界面一般每秒检查状态；CSV 按分钟或部分区间形成记录；默认五分钟批量追加，跨日、休眠和正常退出提交。日志有内容时按批次保存，重复问题合并，不逐帧写日志。

目录不可写、空间不足或写入错误会提示记录异常，不静默改存其他路径。队列及恢复源有上限，异常退出仍可能损失未提交缓冲。CSV 默认保留365天，可设置0为永久；日志按日期和5MiB分卷，保留30天且总量不超过100MiB。

## 查看历史

用本机 Edge／Chrome 打开 viewer/DM-Record-Viewer.html，导入最新一天 v2 CSV，可看当月逐日电量和按年区分的历史月汇总。若要查看过去某月的日明细，导入对应月份 CSV。日志在单独页签导入；不需要服务器、网络或 Agent 在线。详见 [查看器说明](../viewer/USAGE.md)。

本机客户端可按 [IPC.md](IPC.md) 读取实时快照，不必访问串口或磁盘历史。
