SegotepDM 首个 Windows x64 便携版本，包含 DM Agent 和离线记录查看器。

## 功能

- 托盘后台采集、USB 串口连接管理和 11 项电源遥测。
- 分钟 CSV v2 记录、今日估算用电及日／月历史汇总。
- JSON 1.1 本机只读共享内存接口。
- 单 HTML 离线查看器，支持 CSV 趋势、用电汇总和独立日志页签。

## 下载与使用

下载 `SegotepDM-v0.1.0-windows-x64.zip`，解压到有写入权限的目录，运行 `DM-Agent-x64/DmTelemetryAgent.exe`，首次选择电源对应的 USB 串口。系统需要已有可用的 USB 串口驱动，同一端口应由一个应用使用。

离线查看器位于 `DM-Agent-x64/viewer/DM-Record-Viewer.html`，使用 Edge 或 Chrome 打开并导入 CSV／日志。使用说明、数据语义和协议兼容信息随便携包保存在 `docs/`。

`SHA256SUMS.txt` 提供 ZIP 的 SHA256 校验值。`BUILD-INFO.json` 记录构建来源和提交，原创代码采用 MIT，第三方许可随包提供。

## 构建与验证范围

发布包由 GitHub Actions 在 Windows 环境中完成 x64 Release 编译、文件完整性检查，以及可执行文件架构和版本的静态检查。应用运行、硬件兼容性与电量精度需要独立验证；历史设备观察的适用范围见包内 `docs/PROTOCOL.md`。
